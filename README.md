# Reinforced Concrete Slab Load Estimation

## Course

CVL361: Python for Structural Programming

## Objective

Estimate slab loads for a reinforced concrete floor system.

## Problem Statement

Calculate:

- Slab self-weight
- Total dead load
- Total service load
- Factored load

using standard structural engineering equations.

## Input Data

| Parameter | Value |
|------------|------------|
| Thickness | 160 mm |
| Concrete Unit Weight | 25 kN/m³ |
| Floor Finishing | 1.2 kN/m² |
| Ceiling/Services | 0.6 kN/m² |
| Live Load | 3.0 kN/m² |

## Equations

Self Weight:

D = t × γ

Factored Load:

U = 1.4D + 1.6L
